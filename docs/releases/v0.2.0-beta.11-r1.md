Extract it and copy `OpenEval.app` into Applications, retaining any previous version first. Apple Silicon and macOS 13.5+ are required. Official Node.js 24.22.1 is bundled; no ChatGPT desktop installation, npm or manual backend startup is needed. Install Codex CLI separately and use your own ChatGPT login for model work. The workspace is local, while inference uses OpenAI services.

**Apple signing limitation:** OpenEval is ad-hoc signed, not Developer-ID signed or notarized. Normal `codesign --verify --deep --strict` passed; `spctl --assess` returned `rejected`. Downloaded copies may be blocked. No security or quarantine settings were changed. Wait for a signed/notarized build if your Mac or organization blocks this beta.

## What this package contains

Native AppKit/WKWebView app, selected green e icon, trace v2, generic built-in skills, versioned evaluation workspace, offline `.openeval.json` sharing, full third-party notices, original Node license and hashes, bilingual install instructions, validation record and a per-file manifest. No private evaluations, accounts, logs, source conversation history or personal Feishu configuration are included. CLI/MCP source and instructions are in the repository; this desktop ZIP does not install a global npm CLI.

Binary build source: `7b6d528aebea761b6692c8b317ebc7a258b70ca4` in the local development history. The initial private-repository delivery contains an audited source snapshot with additional release documentation and preservation of the repository owner's copyright notice. It does not import local development history. `BUILD.json` inside the ZIP records the exact original binary build provenance; the archive has not been rebuilt or relabeled for this upload.
