unresolved, and normal downloaded-app launch has not passed acceptance.**

Apple M-series Mac and macOS 13.5+ required. Open the DMG, drag OpenEval onto
Applications, eject the installer disk, then open OpenEval from Applications.

## What changed

- A standard Finder drag-to-Applications window replaces the nested ZIP folder.
  Only the app and Applications shortcut are visible, with bilingual instructions.
- All 164 application files match r1, including bundled Node.js 24.22.1, five
  generic skills, runtime manifests, licenses and the native launcher. No model
  behavior or user data is changed by this packaging revision.
- The application still needs the user's separate Codex CLI and ChatGPT login for
  model work. Skill ZIP import still needs `/usr/bin/python3`. The DMG does not
  install a global Node, npm or Codex CLI.

Passing signature integrity only establishes that the ad-hoc signed bytes have
not changed; it does not make the signer an identified developer. A DMG does not
fix Apple's verification warning. Developer ID signing, Apple notarization and
downloaded launch/reopen tests are required before claiming that issue resolved.
See [diagnosis and reproducible build](macos-dmg-status.md) and
[Apple's explanation](https://support.apple.com/en-us/102445).

The existing r1 ZIP and checksums remain as historical assets. Its application
provenance is unchanged; see [r1 details](v0.2.0-beta.11-r1.md). Packaging source
is `scripts/package-dmg.sh` with dmgbuild 1.6.7. Original code is MIT; third-party
licenses retain their own terms. [Privacy review scope](../distribution-privacy.md).
