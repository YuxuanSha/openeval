# OpenEval macOS 本地应用

OpenEval 使用 AppKit 应用窗口和 WKWebView，应用自行启动及停止本机服务。无需另开浏览器，也无需手动执行启动命令。

本机构建位于项目的 `release/OpenEval.app`。在 Finder 中双击打开。若应用代码或数据位于“文稿”目录，macOS 可能要求允许该应用访问文稿文件夹；需要由用户完成系统提示。未处理授权时，子进程可能在读取工作目录前等待，窗口随后显示启动超时。不要通过关闭系统安全保护解决，也不需要完全磁盘访问权限。授权完成后点“重试连接”。退出用 ⌘Q 或关闭最后一个窗口；退出会先停止正在执行的任务、暂停原生目标并保存已有产物，再退出子进程。重新打开不会自动重跑任务。

通用构建默认使用 `~/Library/Application Support/OpenEval/data`，不在应用包中保存个人路径或数据。升级已有工作区时，使用“窗口 → 选择已有工作区…”选择包含 `openeval.sqlite` 和 `blobs` 的原目录；确认后会停止当前执行并打开所选目录，不复制、合并或重新运行任务。目录选择保存在本机应用偏好中，退出重开后继续使用。旧的自定义应用或显式环境变量覆盖优先，存在覆盖时选择入口会说明原因。

窗口菜单的“显示数据文件夹”可以定位数据，“保存当前画面…”可导出当前界面的 PNG，“重新载入”只重新读取页面。应用启动时使用同一用户已登录的 Codex CLI，不复制登录凭据。

输入框加号用于导入文件、文字、链接及 @ 引用，并可启用 CLI 原生目标模式。模型和思考力度菜单只显示当前 CLI 返回的选项。目标留空时使用本条任务作为目标。新 UI 不设置 Token 预算、执行时限或最多轮次；历史记录不改写。停止按钮先暂停目标，再中断当前执行。

## 环境与构建

- 源码构建需要 Node.js 24+；build 11 r1 内测分发包已包含官方 Node.js 24.22.1，无需为打开应用另装 Node 或 ChatGPT。
- 分发包适用于 Apple 芯片、macOS 13.5+。执行评测仍需用户自行安装 Codex CLI 并通过自己的 ChatGPT 账号登录。包中不含 Codex、凭据或飞书连接。
- Skill ZIP 导入目前需要 `/usr/bin/python3`，并非所有 Mac 都已配备；缺失时可先导入单个 `SKILL.md`，不要安装 Xcode 来解决普通应用启动问题。
- 默认监听 `127.0.0.1:4318`；不监听局域网地址。
- 启动器从 `/` 启动 Node；代码入口和持久数据目录分别使用绝对路径，后端拒绝相对数据路径。工作目录不用于选择数据存储，也不会改变文件访问权限。原有已打包应用须重新构建并签名才包含此修复。
- 同一数据目录只允许一个进程使用。端口或数据被占用时，窗口显示错误；不会杀掉占用者。
- 如正在使用命令行启动的同数据服务，应先按原启动方式停止它，再打开应用。
- 编译需要 Xcode 命令行工具。先构建 `web/dist`，再运行 `bash scripts/build-macos.sh`。
- 制作含 Node 的分发包：从官方 HTTPS 地址下载固定版 `node-v24.22.1-darwin-arm64.tar.gz`，运行 `bash scripts/package-macos.sh <该归档绝对路径> <不存在的输出目录>`。脚本验证内置 SHA256，只提取执行文件和完整许可；源码需已提交，输出包含逐文件哈希及源码 commit。下载地址见 `scripts/bundle-macos-node.py`，不会自动安装或登录任何服务。
- 构建脚本拒绝覆盖现有 `.app`；可用 `OPENEVAL_APP_OUTPUT` 指定另一个绝对 `.app` 输出路径，保留旧包。构建时禁止设置 `OPENEVAL_DESKTOP_DATA_DIR`，避免把个人目录带入分发包；该变量只用于进程启动时的本地覆盖。普通 Finder 使用者可直接通过窗口菜单选择既有目录。
- 故障日志在数据目录的 `desktop-logs/window.log`。不要公开上传可能包含本地任务输出的日志。
- 修复版日志会记录 `native-start`、`native-child-started`、`starting/open-data` 与 `ready` 阶段；若只到子进程启动就超时，应检查运行环境和系统文件访问状态，不能据此重跑评测或新建数据目录。

## 签名与发布边界

当前为本机 ad-hoc 签名，没有 Apple Developer ID 签名或公证。Gatekeeper 分发评估为 rejected；本机非隔离属性的自行编译版本已实际启动。未修改 Gatekeeper、隔离属性或系统安全设置。此结果不能代表其他 Mac 可以直接运行下载包。

应用未安装为登录项、系统服务或常驻服务；未写入 Applications。本次没有 GitHub 推送或外部部署。
